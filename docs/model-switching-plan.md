# 桌宠运行中切换模型

批准范围：聊天面板所有标签页共用模型和思考选择；旧模型默认关闭思考，候选默认有限预算（128/512/64），另有关闭和完整思考。记忆整理始终关闭。选择只保留在本次后端运行中，个人资料共享。

1. 后端托管模型：抽取共用启动参数，单个服务级任务先停止自有旧进程（8 秒后强制结束），确认端口释放，再启动并校验目标身份（180 秒）。失败自动恢复；恢复失败仍允许重试。外接服务不可被界面接管。
2. WebSocket 状态及命令：实际/目标模型、可用模型、托管标志、思考档位和切换阶段。切换跨断线继续；打断当前生成/语音，保留文字与 OCR 选窗/裁剪/场景，暂停主动评论和记忆整理。
3. 界面：顶部模型/思考选择、进度、错误与重试；切换期间保留草稿，禁用发送和图片理解，静音与停止观察可用。
4. 验证：隔离进程覆盖切换/资源/冲突/超时/恢复/清理，协议和 UI 回归；真实旧→候选→旧，验收聊天用临时数据库。迁移现有后端为托管模式，保留语音服务，交付旧模型。

不下载资源、不按端口杀进程、不修改 Codex 配置，不提交个人资料。30 分钟真实游戏负载由用户自行验收。
