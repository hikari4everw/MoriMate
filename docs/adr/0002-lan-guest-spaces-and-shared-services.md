# 访客空间独立保存，模型和语音服务全机共用

局域网共享面向少量协助测试的人。主人继续使用仅本机监听的入口，手动启动另一个只包含访客能力的监听器；访客不能通过修改提示词或构造消息使用屏幕感知及主人管理接口。没有直接将原有主人服务暴露到局域网，以便将能力边界落实在后端。

每个浏览器以随机持久身份凭据识别，登录仍需共享密码。身份凭据与本次共享的登录会话分开，数据库只保存凭据哈希；关闭共享或改密码撤销登录，不删除身份及记录。各访客使用独立的数据文件，并分别保存人格覆盖文本，避免给现有所有记忆查询引入容易遗漏的身份过滤。主人保留原数据库。代价是不支持账号找回、跨设备续聊，也不保证地址变化后仍能识别同一浏览器。

模型和语音继续各运行一个实例，接受任一在线使用者切换全机配置。生成及合成通过同一队列串行处理，当前回复完成后主人优先；配置切换停止所有受影响回合，不自动重答。没有按访客常驻多个模型或逐回合重载，避免本机资源不足及测试时反复加载。人格、记忆和静音状态独立于这些共享配置；人格可编辑，双语播报协议固定。
